## 🎯 Learning Objectives

By completing this lab, I should be able to:

- Use a template to provision infrastructure
- Create and configure a Recovery Services vault
- Configure VM-level backup
- Monitor Azure Backup
- Enable VM replication

## 🏗️ Lab Scenario

Practice Azure VM backup, recovery and disaster recovery using Recovery Services and Site Recovery.

## 🧠 What This Lab Teaches

Recovery Services vaults, backup policies, restore points, backup monitoring and Site Recovery replication.

## 🛠️ Prerequisites

- [ ] Azure subscription
- [ ] Appropriate permissions
