## 🎯 Learning Objectives

By completing this lab, I should be able to:

- Create a virtual network with subnets using the portal
- Create a virtual network and subnets using a template
- Configure communication between an Application Security Group and a Network Security Group
- Configure public and private Azure DNS zones

## 🏗️ Lab Scenario

Design virtual networks and subnets for growth, then apply network security and DNS.

## 🧠 What This Lab Teaches

VNet address spaces, subnetting, NSGs, ASGs, DNS zones, records and non-overlapping address design.
