## Troubleshooting discipline

Do not jump directly to a fix.

Use:

```text
Observe
  ↓
Define the failure
  ↓
Check configuration
  ↓
Check dependencies
  ↓
Check permissions
  ↓
Check network path
  ↓
Check logs / activity
  ↓
Change one thing
  ↓
Verify
  ↓
Document
```
