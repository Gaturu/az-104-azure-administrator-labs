# Contributing to the Learning Repository

This repository is primarily a personal AZ-104 practice journal.

## Documentation rules

- Preserve official Microsoft lab numbering.
- Keep official procedures clearly separated from personal notes.
- Never invent screenshots.
- Use relative image paths.
- Record commands that were actually tested.
- Never commit credentials.
- Prefer concise, high-information documentation.

## Screenshot rules

Use:

```text
01-task-01-description.png
02-task-01-description.png
```

Avoid:

```text
Screenshot123.png
image1.png
final.png
```

## Commit style

Prefer small commits:

```text
Complete Lab 04 networking
Document Lab 05 peering issue
Add Lab 07 storage screenshots
Update monitoring exam notes
```
