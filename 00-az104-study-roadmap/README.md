# AZ-104 Study Roadmap

## Purpose

Use this roadmap to move from guided execution to independent Azure administration.

## Progression

### Phase 1 — Guided execution
Perform each official lab while maintaining screenshots and notes.

### Phase 2 — Reduced guidance
Repeat each lab using only this repository's task headings and verification checkpoints.

### Phase 3 — Muscle memory
Rebuild the core scenario from memory.

### Phase 4 — Troubleshooting
Intentionally introduce a safe configuration problem and recover from it.

### Phase 5 — Exam readiness
Explain the service, compare alternatives, identify common traps and reproduce the workflow.

## Weekly review loop

For every completed lab:

- [ ] Perform it once with the official instructions.
- [ ] Record the important settings.
- [ ] Capture screenshots.
- [ ] Record CLI/PowerShell commands.
- [ ] Verify the result.
- [ ] Record one failure or troubleshooting lesson where safe.
- [ ] Perform a second attempt without the official instructions.
- [ ] Write a one-minute revision summary.
- [ ] Update confidence.
